# V1 画符原型（可交互）

**打开方式**：双击 `v1-ui.html`，或拖进 Chrome / Edge / Safari。单文件、零依赖、不需要服务器、不需要联网。

## 能验证什么

| 项 | 怎么试 |
|---|---|
| 构图与信息层级 | 直接看：连续天数 / 时辰胶囊 / 符盘 / 宠物 / 结算面板的相对位置与视觉重量 |
| 画符流程 | 按住符头光点，沿当前虚线画完一笔，松手判定；三笔走完自动结算 |
| 判定门槛 | 右侧"判定阈值"从 0.72 调到 0.60 或 0.85 再画，感受误通过与误杀 |
| 四时辰 | 切"子/卯/午/酉/无常"，看画面色温、胶囊文案、倍率、结算数值一起变 |
| 三张符 | 清心符（竖+两横）/ 聚灵符（框+底纹）/ 御风符（弧+波+钩） |
| 结算数值 | 基础 80 × 时辰倍率 × 连续 7 天 1.05 × 宠物共鸣 1.10 = 139 |
| 失败反馈 | 故意画歪：提示"差一点，重画这一笔"，不判整符失败、不扣任何东西 |

## 不能验证什么（必须在真机上做）

- 120Hz 采样与跟手延迟、ProMotion 下的拖尾顺滑度
- 相机实时预览、滤镜的真实色彩、白墙/暗光场景
- 发热、掉电、SE3 上的帧率
- 震动与音效（原型里没有声音和 Taptic）

## 这个原型里的判定与技术方案同源

32 点等距重采样 → 离散 Fréchet（形似 0.60）→ 切线方向（0.25）→ 端点（0.15）→ 阈值 0.72。
区别只有一处：真机用 `coalescedTouches` 拿 120Hz 原始点，这里用鼠标/触摸事件。所以**阈值本身可以直接搬到 Swift**，但要在 50 条真机轨迹上重新定标。

## v2 改了什么（按"丝滑 / 眼前一亮 / 简洁干净"）

| 改动 | 为什么 |
|---|---|
| 符盘从"完美圆环"退成 1px 纸边 | 圆环像雷达表盘，是 UI 控件语言 |
| 笔锋收细（1.4 → 6pt 渐宽） | 原来的拖尾像荧光棒，现在是笔 |
| 符成落一枚朱砂「敕」印 | 唯一的高光时刻放在"画成"这一下，其余界面保持安静 |
| 符成瞬间墨晕荡开 | 用很低的成本做出"灵气化开"的错觉，比加 300 个粒子便宜 |
| 两层极淡云气（46s/58s 漂移） | 画面不再是一块死黑，但静止看几乎注意不到 |
| 符名与结算标题改宋体 | 无衬线大字距是"发布会 PPT"，宋体才是东方 |
| 粒子从 120 → 90，速度减半、寿命加长 | 从"彩带"变成"香火屑" |

原则：**只在"符成"这一个瞬间亮**，其余时间克制。每屏都亮，等于没有亮。
